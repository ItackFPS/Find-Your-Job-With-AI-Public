# 2.0 qualification report

Date: 2026-11-08. Candidate: `2.0.0rc1`, built from `main` at `71e32d8`. This is the report the readiness
document calls §H, against its §12 checklist (`2026-11-08-2.0-release-decision-readiness.md`).

## Verdict

**The candidate is built and every automated check that can run on this machine passes. It is not ready to
release.** Of the 36 checklist lines, 22 are met, 7 are partly met and 7 are not met. The lines not met need a
person, a clean Windows machine, or the owner's approval. None of them is claimed here.

| | Lines |
|---|---|
| Met | 22 |
| Partly met | 7 |
| Not met | 7 |

The two results that matter most for the release decision:

- **Ranking quality is unproven.** On the 31 held-out real-v2 labels, precision@Strong is 0.000 (95 % CI
  0.000–0.434, 5 offers) and recall@20 is 0.250 (95 % CI 0.046–0.699, 4 accepted offers). This is insufficient
  evidence in either direction. The point estimate is poor and the interval is too wide to conclude anything.
- **The real setup program has not been run for 2.0.** Every install and upgrade result below comes from a staged
  copy of the built application, not from running the installer.

## Disclosures

- **A rehearsal may have started a real scan.** The large-database rehearsal used a read-only copy of the private
  development database with the personal profile. Its earlier LinkedIn and HelloWork scans may count as having chosen
  those sources, so the copy may have briefly started a real scan of an unofficial source. This is inferred, not
  confirmed: its logs were deleted with the temporary folder. For that reason the rehearsal was not repeated. The
  failed dispatch check may share this cause (the pipeline waits while a scan runs).
- **France Travail website fix.** One run failed on all 60 pages with HTTP 500; #168 clears cookies between requests
  and retries a 5xx once. Later runs collected 461 and 481 offers, and one page still failed in one run. The cause,
  load-balancer cookie pinning, is inferred from probes, not proven.
- **The first search downloads 479 MB without a separate confirmation** if the model was not downloaded in the
  wizard.
- **Environment.** All timings come from one development machine. The private Python and application were tested;
  WebView2 and hardware variation were not.

## What only the owner can do

1. Run the real installer on a clean Windows 10 or 11 machine: `acceptance.ps1 -Installer <setup.exe>`.
2. Upgrade a real v1.0.0 install with the real installer, after copying its `data` folder by hand, and compare row
   counts.
3. Perform the documented manual restore once.
4. Run the 3-user usability sessions and a keyboard-only and contrast pass.
5. Validate on three machines.
6. Leave the app for 24 h with the window closed, reboot with autostart on, then disable it.
7. Observe one live France Travail web + EURES duplicate.
8. Decide on the large-database dispatch check above.
9. Approve the release.

At release, before tagging: set the version to `2.0.0`, add the 2.0 config hashes to `KNOWN_RELEASED_DEFAULTS` in
`src/upgrade/config_migration.py`, and rebuild.

## Follow-up

The France Travail website collector reads only IT occupations (`OCCUPATIONS`), which is why 2.0 is stated as tuned
for IT and digital roles. Its sitemap now lists 25,123 pages across about 260 occupations, so extending it is
feasible.
