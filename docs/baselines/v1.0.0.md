# v1.0.0 product baseline

Plan item F0.1 (`docs/plans/2026-10-23-final-update-plan.md`). The 2.0 work is judged against
these figures. Every figure says where it was measured; a figure that was not measured says so
instead of being estimated.

(SHA-256 `b1914d8988d80cb97da2681fd2ebcdb527e90cf20d8c88391046af462aa02af7`).
